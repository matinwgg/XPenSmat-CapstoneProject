# XPenSmat — Intelligent Expense Management for Ghanaian FinTech

XPenSmat is a capstone project exploring intelligent personal-finance management for a Ghanaian/FinTech context. It combines financial-data ingestion, local storage, prediction, natural-language interaction, export, and synchronization.

## System scope

- SMS and bank transaction ingestion
- Local encrypted financial-data storage
- Expense categorisation and prediction
- ML/NLP-assisted interaction
- Data export
- Appwrite synchronization
- Android/mobile application layer
- Separate `ml/` research and training components

## Engineering focus

The project combines full-stack/mobile engineering with applied machine learning, data modelling, secure local storage, API integration, and financial-data integrity.

## Security considerations

Because XPenSmat processes financial information, the project emphasizes least-privilege permissions, protected local state, secure authentication, safe synchronization, release signing, and careful handling of backups and exported data.

## Status

**Capstone / research-oriented prototype.** The project is intended to demonstrate engineering and research capability rather than serve as a production financial service without further security, reliability, compliance, and operational work.

## Research direction

XPenSmat provides a foundation for work on trustworthy FinTech software, secure financial-data processing, applied ML for personal finance, privacy-preserving analytics, and reliable intelligent software systems.
